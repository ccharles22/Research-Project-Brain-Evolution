# data/annotations/

Placeholder for gene/functional annotation reference files used as candidate gene sets in the functional-group relative-rate analyses (`analysis/*/05_*` and `analysis/erecta/06_*`):

- FlyBase gene-list downloads (e.g. neuropeptides, transcription factors)
- GO process term gene lists (e.g. nervous system process, cellular respiration, cuticle development, molting cycle)

These files are not currently committed to the repository; the analysis scripts reference them by an external path (see each script's `params`). Drop local copies here and update the relevant script paths if you want the repository to be self-contained.
